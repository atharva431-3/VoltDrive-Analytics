# VoltDrive Analytics – EV Market Dashboard

A single-page Electric Vehicle (EV) market analytics dashboard built with HTML, CSS, and JavaScript.

## Features

- Overview and key EV market metrics
- Interactive charts and dashboard filters
- Manufacturer comparison
- Battery technology explorer
- Global manufacturing insights
- Sustainability insights
- CSV export and theme toggle

## Demo data

The dashboard uses synthetic/demo data and fictional manufacturer examples. Do not present the displayed figures as verified real-world market data.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. An internet connection is needed for external resources such as Chart.js and Google Fonts.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `VoltDrive-Analytics`.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/VoltDrive-Analytics/`

Replace `YOUR-USERNAME` with your GitHub username and the repository name in the URL if you chose a different name.


## Customization

This edition uses the VoltDrive Analytics branding. The dashboard's displayed market figures are synthetic/demo data and should be described as such in any presentation or report.
